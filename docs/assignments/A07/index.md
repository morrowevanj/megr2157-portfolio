# A7 – FEA on Bracket

## Objective

Use FEA and SolidWorks to identify specific values on the designed A5 Bracket and Link. 

## Analyze

The first step of the process is to use the bracket designed in A5 and create a mesh on the bracket, then run the test, identifying stress, strain, displacement, and safety factor. Then documenting in the spreadsheet the values found.
